# Character portraits

Drop a portrait image here named after the character key, and the onboarding
picker uses it automatically (until then it shows a colour monogram).

Expected files (JPG or PNG — if PNG, update the `photo` path in
`backend/characters.py` `ui_list()`):

    poppy.jpg   luna.jpg   zoe.jpg      (female characters)
    leo.jpg     kai.jpg    ravi.jpg     (male characters)

Guidance:
- Portrait framing (head + shoulders), roughly 3:4, ~800×1000px+.
- Keep a consistent art style across all six so the cast feels like one set.
- Make sure you have the rights to use/ship the image (see the chat notes on
  where to source them — AI-generated custom art is recommended).
